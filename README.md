# 《甲骨问卜》—— 殷墟甲骨文互动 H5

循着一片龟甲：**问卜**——灼龟观兆，问一事之吉凶；**识字**——辨读 12 个甲骨文字，观其从商甲骨 → 周金文 → 秦小篆 → 汉隶 → 今楷的三千年流变。

第六届"创意河南"艺术设计大赛 · 数字媒体（HTML5）作品。零框架、零外部 JS 库、零图片素材服务器依赖。

> 立场：问卜只问**吉 / 凶**，不算命。凶不述灾祸，只劝缓行止争、可择时再卜；卜辞页常驻"此为甲骨文化体验，非算命之断，吉凶在人"。

## 本地预览

```bash
node serve.js
# 打开 http://localhost:8765
```

手机预览（同一 Wi-Fi）：浏览器访问 `http://<本机局域网IP>:8765`（首次可能需在 Windows 防火墙放行 Node）。

## 结构

```
首页（玄鸟龟甲全出血 + 双门户；问卜门为玄漆暗色预告）
 ├─ 问卜 ★夜祭三屏（.night 玄漆暖黑：近黑暖褐漆底 + 骨白文字 + 暖金发丝 + 朱砂灼痕）
 │   ① 命龟：心中默问所疑，可择事类（出行/行事/相见/抉择/杂事，源自甲骨卜辞）
 │   ② 灼龟：按住龟甲 1.25s 施火——火候环渐满、火光呼吸明灭、余烬自火点上腾，
 │           暗角晕影聚焦龟甲；松手即败（"火候未足"）。火足则点火爆闪、震屏、迸星
 │           （层叠爆响 + 触感振动），三层灼热裂纹（辉光/朱砂/白炽核心）错峰描出：
 │           吉=主干顺直、两条平出短璺；凶=左右交替闪电式折行、多短枝。兆不出甲缘。
 │           黑底龟甲以 mix-blend-mode:screen 消底，如古骨在暗中受火自发光
 │   ③ 卜辞：夜祭专用底图（上玄鸟青烟 / 中灼晕火星 / 下远山暗影铜纹），干支落款
 │           （年/日真实干支）、占辞只述兆纹与行止态度
 │           操作：保存卜辞（暗色长图）/ 再占一次 / 去识字
 └─ 识字 ★全程保持浅色纸本（白日识字、夜阑问卜）
     12 字四选一（首次答错不扣分）→ 答完第 4、9 字插入拓印
     拓印：全场墨黑，擦刮显出骨白字形如真拓片
     观变：五阶段字形时间轴（点节点 / 左右滑动）
     结果：卷轴卜辞，评级（大吉/吉/小吉/待问）+ 竖排判词
           操作：保存成绩图（浅色长图）/ 再寻一次 / 去问卜
```

两模式结果页互相导流，闭环传播：**晒卜辞 → 引流识字；晒成绩 → 引流问卜**。

## 设计语言

"朱墨分职"（frontend-design plugin 工作法）：朱砂只用于"卜"（评级/卜印/灼裂纹），
青铜只用于答对确认，赭金只做发丝细线；零圆角卡片、零柔影；动效只在首页一次入场编排。

**白日识字，夜阑问卜**：问卜三屏以 `.night` 作用域翻为「玄漆暖黑」夜祭色调（老师指导：
底板需更沉重以承占卜的神秘感），首页与识字全流程保持浅色纸本，两套色系互不污染。
暗底合成要点：龟甲素材处理为纯黑底 → `mix-blend-mode:screen`（导出 canvas 用
`globalCompositeOperation='screen'`），黑场消尽、骨甲自发光；火光粒子用 `'lighter'` 加色。

## 字形来源

汉典字源库所收录真实甲骨/金文/小篆实例描摹 SVG，每字所选实例依据
`创意河南-殷墟甲骨文信息可视化/01-资料研究/字形遴选表-v1.md`（含《合集》《集成》著录号）。
构建时自动剔除汉典水印（近白填充组/路径）并统一为 `currentColor`。

重建：`node build-glyphs.js`

## 美术

四张关键美术（hero / shell / result / oracle-bg）由 Seedream 5.0 Pro 文生图，
提示词见 `prompt-*.txt`，经手动色阶/重采样处理（shell 白底映射见 cdp-whiten.js）。
画面无任何文字（青铜回纹为装饰；result 角落红印为无字空印，界面与导出均裁除）。
Agent Plan 不含可用的 Seedance 视频模型，故全片动效皆为程序化实现（CSS/Canvas/WebAudio）。
